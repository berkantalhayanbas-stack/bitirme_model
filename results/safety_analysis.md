# Safety analysis: hazard → cause → mechanism → measured reaction

FMEA-style summary of the BMS ECU safety mechanisms, compiled 2026-11-22 from the HIL, Monte Carlo and unit-test results (thesis notes). The figures come from earlier test runs; this table did not re-run any test.

Scope note: this is **not** a full ISO 26262 process. There is no HARA, ASIL assignment, safety goals or requirement traceability. It shows which mechanisms exist, what triggers them, and the measured detection and reaction times. States: NORMAL → DERATE → LIMP-HOME (25 % current floor) → SAFE-STOP (I_allow = 0, contactor open, latched until restart).

## How to read it
- **Graded response (H1, H2, H4, H7, H8).** The ECU limits current before it disconnects. Opening a contactor while driving can be more hazardous than the cause (Lelie 2018). SAFE is the last layer and is latched.
- **Fault classes (Barreras 2016, Table II).** The cases map to functional tests (H1, H4, H7, H8), sensor malfunction (H5, H6), interface faults (H9, H10) and system-component faults (H11, H12).
- **Out of scope:** insulation monitoring (ISO 6469-1), redundant cell-voltage path, pre-charge and contactor-weld detection, cybersecurity (SecOC, secure boot, HSM). See Limitation and future work.
