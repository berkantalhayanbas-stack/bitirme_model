\chapter{CAN database}\label{app:dbc}
The message encoding is implemented once in \texttt{bms\_can.c} and copied to every node. For tool support, a DBC file (\texttt{tools/can/bms.dbc}, 11 messages, 101 signals, Intel byte order) describes the same frames, including the counter and CRC as signals and the receiver rules in comments. It was checked by encoding 14\,000 random frames with \texttt{bms\_can.c}, decoding them with the DBC and re-encoding them: all were byte-identical. \todo{frame layout table per message}
